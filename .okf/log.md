Supports both open and PBKDF2 + AES-256-GCM encrypted `.slate` files directly via binary Yjs CRDT mutations. Added `AGENTS.md` autonomous agent guide and `.okf/architecture/headless-cli.md`.

Upgraded `HistoryPanel` with dual tabs (`📋 Activity` and `💾 Snapshots`), instant text search, author filter, action type filters, relative time display, and a 1-click `🎯 Jump to item` camera locator (`api.scrollToContent` / smooth canvas pan). Added `History (N)` counter badge to the status bar.

Added member list picker dropdown and 1-click suggestion chips (`+ 🐙 username`) to `TaskDetailsModal`.
